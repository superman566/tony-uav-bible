> - **Part 2**：注意力机制是什么，手算一遍

## Part 1：前置知识——RNN 与 LSTM

### 为什么需要专门处理"序列"

**一句话理解**：有一类数据，**顺序本身就是信息**——换个顺序意思就全变了，这类数据叫**序列数据（Sequential Data）**。

例子：「狗咬人」和「人咬狗」，用的字一模一样，只是顺序不同，意思完全相反。类似的还有一段语音、一段视频，或者无人机按时间记录下来的一串惯性测量单元（Inertial Measurement Unit，IMU）传感器读数。

[卷积神经网络（Convolutional Neural Network，CNN）](/ai-yolo/cnn-basics)看一张图时，是把所有像素一起处理的；而读一句话，需要**按顺序读，一边读一边记住前面读过的内容**。RNN 就是为此设计的。

### RNN：带"记忆"的神经网络

**一句话理解**：**循环神经网络（Recurrent Neural Network，RNN）**每次读一个词，把"这个新词"和"之前的记忆"合在一起，更新成新的记忆，再带到下一步。

这份记忆叫**隐藏状态（Hidden State）**，写作 `h`。其中 `tanh` 是双曲正切函数（Hyperbolic Tangent），作用是把结果压缩到 -1~1 之间：

```
h_t = tanh( W_x × x_t  +  W_h × h_(t-1)  +  b )
       ↑       ↑               ↑
     压缩到   当前输入        上一步的记忆
    -1~1之间
```

**数字例子**（为了简单，全部用单个数字）：设 `W_x = 0.5`，`W_h = 0.8`，`b = 0`，一开始的记忆 `h_0 = 0`。输入序列是 `x = [1, 0, 0]`，只有第 1 步有信号：

```
第1步: h_1 = tanh(0.5×1 + 0.8×0)    = tanh(0.50) ≈ 0.46
第2步: h_2 = tanh(0.5×0 + 0.8×0.46) = tanh(0.37) ≈ 0.35
第3步: h_3 = tanh(0.5×0 + 0.8×0.35) = tanh(0.28) ≈ 0.27
```

可以看到，第 1 步的信息一路传了下去（0.46 → 0.35 → 0.27），但**每走一步都会变淡一些**。

**关键点**：每一步用的都是**同一组权重（Weight）** `W_x` 和 `W_h`，也就是把同一个"小网络"反复使用。名字里的"循环"说的就是这个。

### RNN 的致命问题：梯度消失

**一句话理解**：句子一长，开头的信息传到后面就几乎没了，模型**学不会**长距离依赖（Long-Range Dependency）。

训练的时候，[反向传播（Backpropagation）](/ai-yolo/dl-basics)要把梯度（Gradient）从后往前一步一步传回去，每经过一步大约乘上一个小于 1 的数，结果会越乘越小：

```
假设每步梯度乘以 0.5，传 20 步：
0.5^20 ≈ 0.00000095   → 几乎为 0
```

这个现象叫**梯度消失（Vanishing Gradient）**：靠前那些步几乎收不到梯度，参数就学不到东西。

> 例子：「我在**法国**长大，……（中间 30 个词）……，所以我说一口流利的 ___」
> 要填出"法语"，必须记住 30 多个词之前的"法国"。普通 RNN 基本做不到。

### LSTM：会"选择性记忆"的 RNN

**一句话理解**：**长短期记忆网络（Long Short-Term Memory，LSTM）**在 RNN 的基础上加了一条"记忆传送带"，再配上三个"阀门"，由它们决定**忘掉什么、记住什么、输出什么**。

#### 记忆传送带：细胞状态（Cell State）

细胞状态写作 `c`。它就像一条直通的传送带，信息放上去以后可以几乎不变地一直往后传，不会像 RNN 那样每一步都被 `tanh` 压一次。

#### 三个门（Gate）

三个门的取值都在 0 到 1 之间（用 [S 型函数（Sigmoid）](/ai-yolo/dl-basics#常见的激活函数)算出来），相当于三个"阀门开度"：

| 门 | 英文 | 作用 | 0 表示 | 1 表示 |
|---|---|---|---|---|
| 遗忘门 | Forget Gate `f` | 旧记忆要保留多少 | 全忘掉 | 全保留 |
| 输入门 | Input Gate `i` | 新信息要写入多少 | 不写 | 全写入 |
| 输出门 | Output Gate `o` | 这一步要对外输出多少记忆 | 不输出 | 全输出 |

核心更新公式（其中 `c̃_t` 叫**候选细胞状态（Candidate Cell State）**，就是这一步准备写进记忆的新信息）：

```
c_t = f × c_(t-1)  +  i × c̃_t        (c̃_t: 这一步的"候选新信息")
h_t = o × tanh(c_t)
```

#### 数字例子：记住"法国"

1. 读到"法国"时，把它写进记忆：`c = 0.9`。
2. 后面 30 个无关的词，模型学会了这样设置阀门：`f = 1.0`（旧记忆全部保留），`i = 0`（不写入新信息）：

```
c = 1.0 × 0.9 + 0 × (...) = 0.9
c = 1.0 × 0.9 + 0 × (...) = 0.9
...（30 步之后）
c = 0.9   ← 记忆完好无损！
```

3. 读到"说一口流利的"时，输出门打开（`o = 1`），这份记忆就被拿出来用，模型预测出"法语"。
4. 读到下一个句子、主语换人了，遗忘门关小（`f = 0`），旧记忆就被清空。

**为什么梯度不容易消失？** 在传送带上，每一步梯度乘的是 `f`。只要模型学会让 `f ≈ 1`，梯度传 30 步基本还是原来的大小，而不会像 RNN 那样衰减成 `0.5^30`。

**生活类比**：

- RNN 像只靠脑子记事，事情一多，早先的就忘了。
- LSTM 像带了个笔记本：重要的事写下来（输入门），过时的划掉（遗忘门），需要时翻出来看（输出门）。

### RNN/LSTM 的局限：Transformer 要解决的问题

LSTM 虽然比 RNN 强很多，但仍然有两个根本问题：

1. **必须一个词一个词地顺序处理**：第 100 个词要等前 99 个都算完才能算，**没法并行（Parallelize）**，图形处理器（Graphics Processing Unit，GPU）的算力用不满，训练很慢。
2. **距离还是有影响**：信息仍要一步一步接力传过去，句子特别长时依然会丢失。

**Transformer**（中文一般不翻译，直接叫 Transformer；出自 2017 年的论文《Attention Is All You Need》）的做法是干脆不要"循环"，改用**注意力机制（Attention Mechanism）**：每个词**直接看句子里的所有其他词**，自己判断该关注谁。

- 第 1 个词和第 100 个词之间只差"一步"，不需要中间 99 步接力传递。
- 所有词可以**同时计算**，速度快。

```
RNN/LSTM:    词1 → 词2 → 词3 → ... → 词100   (接力传话，慢，会失真)
Transformer: 每个词 ⇄ 所有词                 (开会，所有人直接对话)
```

## Part 2：注意力机制

### 注意力机制（Attention Mechanism）是什么

**一句话理解**：读到一个词时，回头把句子里的其他词都看一遍，**挑出跟它最相关的几个，重点参考它们**。

例子：

> 小猫喝了牛奶，因为**它**渴了。

读到"它"的时候，你会下意识往前看：它指的是"小猫"还是"牛奶"？很快就能确定是"小猫"，于是你理解"它"时，脑子里装的主要是"小猫"。**注意力机制（Attention Mechanism）**就是让模型也学会这么做。

**生活类比**：开会讨论一个问题，你不会平均地听每个人的意见，而是**多听懂行的人、少听不相关的人**。"注意力"就是你分给每个人的"听取比例"。

**正式一点的定义**：

> 注意力机制是一种**动态地**为输入信息分配注意力权重（Attention Weight），从而让输出聚焦于最相关输入部分的机制。

这句话里有两个词值得多看一眼：

- **动态**：权重是根据当前输入**现算出来的**，不是训练完就固定不变。同样是"它"，在「小猫喝了牛奶，因为它渴了」里关注"小猫"；换成「小猫打翻了牛奶，因为它装得太满了」，就会改成关注"牛奶"。这是注意力和普通网络层，比如卷积层（Convolutional Layer）、全连接层（Fully Connected Layer），最大的区别：

```
卷积/全连接层: 输出 = 固定权重 × 输入            (权重和输入无关)
注意力:        输出 = 权重(由输入现算) × 输入     (输入一变，权重跟着变)
```

- **聚焦**：不等于"只看一个"。注意力是**软的（Soft）**，每个词都会分到一点权重，只是有大有小。输出是**所有输入按权重加起来**的结果，不是挑一个、扔掉其他的。

### 三个关键信息：Query、Key、Value

**一句话理解**：每个词带着一个问题（**Query**），去和其他词的标签（**Key**）比对，越匹配，就越多地拿走对方的内容（**Value**）。

| | 英文 | 它回答的问题 |
|---|---|---|
| Q | 查询（Query） | 我想找什么？ |
| K | 键（Key） | 我有什么？（给别人用来匹配） |
| V | 值（Value） | 我能提供什么内容？ |

**生活类比：在图书馆找书**

- **Query**：你心里想找的主题，比如"无人机避障"。
- **Key**：每本书封面上的标签。
- **Value**：书里的正文。

你拿想找的主题去对照每本书的标签，最相关的那几本多读，不相关的少读或不读。

**套回句子**：「小猫喝了牛奶，因为**它**渴了」

- "它"的 Query 是"我指的是谁？"
- "小猫"的 Key 和这个问题最匹配，"牛奶"的 Key 不太匹配。
- 所以"它"主要拿走了"小猫"的 Value，模型就理解了"它"指的是小猫。

> **一句话记住**：Q 和 K 决定**关注谁**，V 决定**拿到什么**。

三个向量都是由词向量（Word Embedding）`x` 分别乘上三个**可学习的权重矩阵（Weight Matrix）**得到的：

```
Q = x × W_Q      K = x × W_K      V = x × W_V
```

也就是说，"该关注谁"不是人写死的规则，而是模型在训练中**自己学出来的**。

### 注意力分数（Attention Score）：两个词有多相关

**一句话理解**：注意力分数就是"两个词有多相关"的打分，**分数越高，越值得关注**。

**例子**：「小猫喝了牛奶，因为**它**渴了」

"它"在想"我指的是谁？"，于是给句子里每个词打一个分：

```
小猫  →  高分   (很可能就是我)
牛奶  →  低分   (不太像)
因为  →  很低   (几乎无关)
```

分数最高的"小猫"，就是"它"最该关注的词。

**分数从哪来**：拿"我想找什么"（Query）去和"你有什么"（Key）比一比，**越对得上，分数越高**。

**生活类比：面试打分**

你是面试官，手里有一份岗位要求（**Query**），每个候选人递上自己的简历（**Key**）。你对照岗位要求逐个打分，越符合要求分数越高。这个"对照打分"的结果，就是注意力分数。

**容易混淆：分数 vs 权重**

- **注意力分数（Attention Score）**：原始打分，比如 `小猫 8 分，牛奶 2 分`，数字大小没有固定范围。
- **注意力权重（Attention Weight）**：把分数换算成**加起来等于 100% 的比例**，比如 `小猫 80%，牛奶 15%，因为 5%`。

> **一句话记住**：**先打分，再换算成比例**。模型最后按这个比例去"听取"各个词的信息（也就是拿走多少 Value）。

### 一步步算一遍：「它」在关注谁

为了简单，句子只取 3 个词 `[小猫, 牛奶, 它]`，每个向量只用 2 个数字。我们来算"它"这个词：

```
"它"的 Query:  q = [1, 0]          (可以理解成"我在找一个动物")

Keys:   小猫 k = [2, 1]    牛奶 k = [0, 1]    它 k = [1, 0]
Values: 小猫 v = [1, 0]    牛奶 v = [0, 1]    它 v = [0.5, 0.5]
```

**第 1 步：算注意力分数**。用 q 和每个 k 做**点积（Dot Product）**，也就是对应位置相乘再相加。点积越大，两个向量越"对得上"，分数就越高：

```
小猫: 1×2 + 0×1 = 2
牛奶: 1×0 + 0×1 = 0
它:   1×1 + 0×0 = 1
```

**第 2 步：变成比例**。用[归一化指数函数（Softmax）](/ai-yolo/dl-basics#常见的激活函数)把分数换算成加起来等于 1 的注意力权重：

```
e^2 = 7.39,   e^0 = 1,   e^1 = 2.72        总和 = 11.11

小猫: 7.39 / 11.11 ≈ 0.67
牛奶: 1    / 11.11 ≈ 0.09
它:   2.72 / 11.11 ≈ 0.24                  (0.67 + 0.09 + 0.24 = 1)
```

**第 3 步：按比例混合**。用这些权重把每个词的 V 加起来：

```
输出 = 0.67 × [1, 0]  +  0.09 × [0, 1]  +  0.24 × [0.5, 0.5]
     = [0.67 + 0 + 0.12,   0 + 0.09 + 0.12]
     = [0.79, 0.21]        ← 非常接近"小猫"的 [1, 0]
```

算完之后，"它"的新表示（Representation）里**装的主要是"小猫"的信息**，模型就"知道"了它指的是小猫。

> 这个例子为了数字好算，省略了"除以 √d_k"这一步，[Part 4](#缩放因子-scaling-factor-为什么要-除以-√d-k) 会讲它是干什么的。

## Part 3：什么是 Transformer

### 一句话理解：Transformer 是什么

**一句话理解**：Transformer 是一种**完全靠注意力机制处理序列**的神经网络架构（Architecture）。它不像 RNN 那样一个词一个词地往后传，而是把整句话一次送进去，让所有词**一轮一轮地"开会"互相看**，最后得到输出。

**例子**：原版 Transformer 是用来做机器翻译（Machine Translation）的：

```
输入:  我 爱 你
输出:  I love you
```

**生活类比：一家翻译公司**

- **阅读组**：先把中文原文从头到尾读懂，整理成一份"理解笔记"。这就是**编码器（Encoder）**。
- **写作组**：拿着这份笔记，一个词一个词地写出英文译文，写每个词时都会回头翻一翻笔记。这就是**解码器（Decoder）**。

Part 2 讲的注意力机制，就是这两个组里每个人干活时用的核心方法。

### 整体结构：一张图看懂

先看全貌，后面再一块一块拆开讲：

```
        原文「我 爱 你」                     已经写出的译文「<开始> I love」
              │                                         │
   ① 词嵌入 + 位置编码                        ① 词嵌入 + 位置编码
              │                                         │
   ┌──────────▼──────────┐                   ┌──────────▼──────────┐
   │ ② 编码器层  × 6      │                   │ ③ 解码器层  × 6      │
   │   多头自注意力       │                   │   掩码自注意力       │
   │   前馈网络           │ ── 理解笔记 ────▶ │   交叉注意力         │
   └─────────────────────┘                   │   前馈网络           │
                                             └──────────┬──────────┘
                                                        │
                                             ④ 线性层 + Softmax
                                                        │
                                               下一个词:「you」
```

整个流程就四步：

| 步骤 | 做什么 | 类比 |
|---|---|---|
| ① 输入 | 把词变成向量，并标上"第几个" | 把文字录入电脑 |
| ② 编码器 | 原文的词反复开会，读懂原文 | 阅读组写理解笔记 |
| ③ 解码器 | 看着笔记，一个词一个词写译文 | 写作组翻译 |
| ④ 输出 | 从词表里挑出最可能的下一个词 | 落笔写下一个词 |

### 第 ① 步：把词变成向量——词嵌入 + 位置编码

模型只认数字，所以第一步要把文字变成向量。

**切词**：先把句子切成一个个小单位，叫**词元（Token）**。可以简单理解成"一个词"或"一个字"。

**词嵌入（Word Embedding）**：模型内部有一张"词典表"，每个词元对应一行数字，查表就能拿到它的向量。原版 Transformer 里每个向量有 512 个数字：

```
"我"  →  [ 0.21, -0.53,  0.08, ...]   (512 个数)
"爱"  →  [-0.37,  0.91, -0.12, ...]   (512 个数)
"你"  →  [ 0.44,  0.02,  0.67, ...]   (512 个数)
```

这张表一开始是随机的，训练时**和模型其他部分一起学**，学完以后，意思相近的词（比如"猫"和"狗"）向量也会比较接近。

**位置编码（Positional Encoding）：告诉模型谁在第几个**。注意力有一个小毛病：回头看 Part 2 里"它"的计算，如果把句子打乱成 `[它, 牛奶, 小猫]`，"它"的打分和输出**完全不变**，因为点积只看内容、不看位置。这样就又回到了 Part 1 开头的问题：单靠注意力，分不清「狗咬人」和「人咬狗」。

所以在送进编码器之前，要给每个词向量**加上一个代表"第几个位置"的向量**：

```
送进编码器的向量 = 词向量 + 位置向量
"狗"在第1位:  [狗的向量] + [位置1的向量]
"狗"在第3位:  [狗的向量] + [位置3的向量]      ← 和上面不一样了
```

这样同一个词出现在不同位置，向量也就不一样了，模型就能分清顺序。整句「我 爱 你」处理完，就是一个 3 个词 × 512 维 = **3 × 512 的矩阵**，送进编码器。

### 第 ② 步：编码器（Encoder）——反复"开会"读懂原文

**一句话理解**：编码器由 **6 个一模一样的编码器层（Encoder Layer）**叠起来。每一层做两件事：**先开会交流，再各自消化**。

```
一个编码器层:
  输入 (3×512)
    → 多头自注意力   (开会: 每个词去看其他所有词，交换信息)
    → 前馈网络       (消化: 每个词自己回去想一想)
  输出 (3×512)       ← 形状不变，可以直接送进下一层
```

**开会：多头自注意力（Multi-Head Self-Attention）**。就是 Part 2 讲的注意力，"它"在这一步知道了自己指的是"小猫"。词与词之间的信息交换**只发生在这一步**。具体怎么算，见 [Part 4](#自注意力-self-attention-句子里的词互相看)。

**消化：前馈网络（Feed-Forward Network，FFN）**。就是一个普通的两层全连接网络，**每个词单独过一遍，互不干扰**。它先把向量撑大，再压回原来的大小：

```
每个词:  512 维  →  放大到 2048 维  →  压回 512 维
        (先展开想得更细，再总结成原来的长度)
```

**生活类比**：开完会（注意力），每个人回到自己的工位，把会上听到的内容结合自己的知识再琢磨一遍（前馈网络）。

**两个让深层网络能训练起来的小技巧**：每做完一件事（开会或消化），都会再加两步。

- **残差连接（Residual Connection）**：输出 = 输入 + 这一步新学到的东西。和 [ResNet 的跳跃连接](/ai-yolo/cnn-basics#解决方案-残差学习-跳跃连接-residual-learning-skip-connection)是同一个思路：

  ```
  输入:          [1.0, 2.0]
  注意力算出:    [0.1, -0.3]          (新学到的"修改意见")
  残差后输出:    [1.0+0.1, 2.0-0.3] = [1.1, 1.7]
  ```

  就像用"修订模式"改文档：原文保留，只在上面加修改。就算这一层什么都没学到，原来的信息也不会丢。

- **层归一化（Layer Normalization）**：把每个词的向量拉回"平均值 0、标准差 1"左右（**标准差（Standard Deviation）**可以理解成"这些数平均离平均值有多远"），防止数字越往后传越大或越小。和 [批归一化（Batch Normalization）](/ai-yolo/nn-training-optimization#batch-normalization-批归一化)目的一样，区别是它**对每个词自己的那串数字**做归一化：

  ```
  某个词的向量:  [2, 4, 6]
  平均值 = 4，标准差 ≈ 1.63
  归一化后:      [(2-4)/1.63, (4-4)/1.63, (6-4)/1.63] ≈ [-1.22, 0, 1.22]
  ```

**为什么要叠 6 层**：每多开一轮会，理解就深一层。可以粗略地这样想：

```
第 1 层:  看出词和词之间的表面关系   ("它"附近有"小猫"和"牛奶")
中间层:   看出语法关系               ("它"是"渴了"的主语)
高层:     看出整句话的意思           ("它"= 小猫，小猫渴了所以喝牛奶)
```

编码器最后输出一个 3 × 512 的矩阵，每一行是一个词**结合了整句上下文**之后的向量，这就是那份"理解笔记"。

### 第 ③ 步：解码器（Decoder）——一个词一个词往外写

**一句话理解**：解码器也是 6 层叠起来，每层比编码器多一步：**先看自己已经写了什么，再回头查原文，最后自己消化**。

```
一个解码器层:
  → 掩码自注意力   (看看自己已经写了哪些词，不许偷看后面的)
  → 交叉注意力     (拿着当前要写的词，去编码器的"理解笔记"里找对应的原文)
  → 前馈网络       (消化)
  (每一步后面同样有残差连接 + 层归一化)
```

**掩码自注意力（Masked Self-Attention）：不许偷看答案**。写第 3 个词时，只能参考第 1、2 个词，后面的词要"遮住"，就像考试时把还没轮到的答案盖起来。做法是把"不许看"的位置的分数设成负无穷（-∞），Softmax 之后权重就变成 0（数字仅为示意）：

```
正在写的词 ↓     I      love    you
I               1.00    0       0        ← 只能看自己
love            0.40    0.60    0        ← 看不到 "you"
you             0.20    0.30    0.50     ← 前面都能看
```

**交叉注意力（Cross-Attention）：对照原文翻译**。Q 来自译文，K 和 V 来自编码器输出的原文"理解笔记"。相当于一边写译文，一边拿着当前要写的词去原文里找对应的部分。比如写到 "cat" 时，它的 Q 去原文里打分，就会主要关注"小猫"。

到这里，Transformer 里用到注意力的三个地方就齐了：

```
① 编码器里的自注意力:      原文的词互相看              → 理解原文
② 解码器里的掩码自注意力:  译文只能看已经写出来的词    → 不许偷看答案
③ 交叉注意力:              译文回头去看原文            → 对照着翻译
```

> ①② 都是"自己看自己"（Q、K、V 来自同一句话），所以叫**自**注意力；③ 是"译文看原文"（Q 和 K、V 来自两句话），所以叫**交叉**注意力。

**写译文的过程**：解码器每次只往外写**一个词**，写完把它接到输入末尾，再写下一个，直到写出"结束"符号为止。这种"用自己前面的输出当下一步的输入"的方式叫**自回归（Autoregressive）**：

```
第 1 轮:  输入 <开始>                →  写出 I
第 2 轮:  输入 <开始> I              →  写出 love
第 3 轮:  输入 <开始> I love         →  写出 you
第 4 轮:  输入 <开始> I love you     →  写出 <结束>     ← 翻译完成
```

**训练时和使用时不一样**：

- **训练时**：正确译文是已知的，可以把整句一次送进去**并行计算**，靠上面的掩码遮住后面的词，防止偷看答案。所以训练依然很快。
- **使用时（推理，Inference）**：答案不知道，只能像上面那样一个词一个词地生成。这也是 ChatGPT 这类模型回答时"一个字一个字往外蹦"的原因。

### 第 ④ 步：输出——从词表里挑下一个词

解码器最后输出的是一个 512 维向量，还不是词。最后一步：

1. **线性层（Linear Layer）**：模型认识的所有词组成一张**词表（Vocabulary）**。线性层把 512 维向量变成"词表里每个词一个分数"。假设词表有 30000 个词，就得到 30000 个分数。
2. **Softmax**：把分数换算成概率，挑概率最大的那个词。

```
第 3 轮，解码器已经写了「<开始> I love」，下一个词的概率:

  you    85%   ← 最大，选它
  it      6%
  her     4%
  ...    (其余 29997 个词加起来 5%)
```

### 原版 Transformer 的关键数字

| 项目 | 数值 | 含义 |
|---|---|---|
| 编码器层数 | 6 | 原文开 6 轮会 |
| 解码器层数 | 6 | 译文开 6 轮会 |
| 向量长度 `d_model` | 512 | 每个词用 512 个数表示 |
| 注意力头数 | 8 | 每次开会请 8 个"专家"，见 [多头注意力](#多头注意力-multi-head-attention-请几个-专家-从不同角度看) |
| 每个头的维度 `d_k` | 64 | 512 ÷ 8 = 64 |
| 前馈网络中间层 | 2048 | 512 → 2048 → 512 |

### 三种变体：只用编码器、只用解码器、两个都用

原版是"编码器 + 解码器"，后来大家发现，**只拿其中一半**也很好用：

| 结构 | 代表模型 | 擅长 | 类比 |
|---|---|---|---|
| 只用编码器（Encoder-only） | BERT | **理解**：文本分类、情感判断 | 阅读理解：读完回答问题 |
| 只用解码器（Decoder-only） | GPT、Claude 等大语言模型（Large Language Model，LLM） | **生成**：续写、对话 | 写作：根据开头往下写 |
| 编码器 + 解码器（Encoder-Decoder） | 原版 Transformer、T5 | **转换**：翻译、摘要 | 翻译：读完一种写成另一种 |

例子：输入「这部电影太好看了」

- BERT（编码器）：输出"正面评价"。
- GPT（解码器）：接着往下写"我已经推荐给朋友了……"。
- 翻译模型（编码器 + 解码器）：输出 "This movie is great"。

> 只用解码器的模型没有编码器，也就没有"原文笔记"可查，所以每层都**去掉了交叉注意力**，只剩"掩码自注意力 + 前馈网络"。

### Transformer 和图像、目标检测有什么关系

Transformer 虽然诞生在文字领域，但后来也被用到了图像上。关键是想办法**把图片也变成"一串词"**：

**视觉 Transformer（Vision Transformer，ViT）**：把图片切成一个个小方块，叫**图像块（Patch）**，每个小方块就当成一个"词"：

```
一张 224 × 224 的图片，切成 16 × 16 的小块:
  每行 224 ÷ 16 = 14 块，共 14 × 14 = 196 块
  → 相当于一句 196 个"词"的句子，送进 Transformer 编码器
```

和 [CNN](/ai-yolo/cnn-basics) 的区别：CNN 的卷积核每次只看一小片邻近区域，要叠很多层才能"看到"整张图；ViT 里第 1 层开始，每个图像块就能直接看到所有其他图像块。

**检测 Transformer（Detection Transformer，DETR）**：用 Transformer 直接做目标检测。它准备一组固定数量的**物体查询（Object Query）**（原版是 100 个），每个物体查询就像一个"找物体的名额"，负责找出一个物体，找不到就输出"没有物体"。因为一个物体只占一个名额，**一个物体只出一个框**，所以天生不需要非极大值抑制（Non-Maximum Suppression，NMS）去重。YOLO26 的主体仍然是 CNN，但它的 [NMS-Free 设计](/ai-yolo/yolo-architecture#nms-free-彻底做成端到端)走的也是"一个物体只配一个框"这条路，思路和 DETR 是相通的。

## Part 4：深入注意力——Transformer 里的注意力怎么算

### 一句话：多头 + 自注意力 + 缩放点积

Part 3 讲了注意力用在哪里，这一部分拿放大镜看它具体怎么算。注意力有很多种做法，Transformer 用的这一种，名字可以拆成三块：

| 名称 | 大白话 |
|---|---|
| **自注意力（Self-Attention）** | 句子里的词**互相看自己这句话里的其他词**。Part 2 里"它 → 小猫"就是自注意力。 |
| **缩放点积注意力（Scaled Dot-Product Attention）** | 规定了怎么打分：用点积打分，再**除以一个数缩小一下**。 |
| **多头注意力（Multi-Head Attention）** | 同时请好几个"专家"，各自从不同角度去看，最后把结论合起来。 |

下面一块一块讲。

### 自注意力（Self-Attention）：句子里的词互相看

**一句话理解**：一句话里的词**互相看**，每个词都参考同一句话里的其他词，来理解自己。"自"的意思是：Query、Key、Value **都来自同一句话**，不去看别的句子。

**例子**：「小猫喝了牛奶，因为它渴了」

- "它"去看其他词，发现"小猫"最相关，于是知道"它"指的是小猫。
- "喝了"也在看，发现"牛奶"最相关，于是知道喝的是牛奶。
- **每个词都同时在做这件事**，算完以后，每个词都带上了整句话的上下文（Context）信息。

**生活类比：圆桌会议 vs 传话游戏**

- **自注意力**像圆桌会议：每个人都能直接听到其他所有人说话，再结合大家的发言更新自己的理解。
- **RNN** 像传话游戏：一个人传给下一个人，一直往后传，传得越远越容易失真。

**和交叉注意力（Cross-Attention）的区别**：

- **自注意力**：同一句话里的词**互相看**，用来理解这句话本身。
- **交叉注意力**：一句话去看**另一句话**。比如翻译时，正在写的英文去对照中文原文（Part 3 的[解码器](#第-3-步-解码器-decoder-——一个词一个词往外写)一节讲过）。

**所有词同时算**：前面只算了"它"一个词，实际上每个词都会拿自己的 Q 去和所有词的 K 打分。所有结果可以排成一张"谁关注谁"的表（前两行数字仅为示意）：

```
              被关注 →   小猫    牛奶     它
关注者 ↓  小猫          0.50    0.30    0.20
          牛奶          0.40    0.45    0.15
          它            0.67    0.09    0.24    ← 就是上面算的那一行
```

每一行加起来都是 1。关键是：**这张表可以用一次矩阵乘法（Matrix Multiplication）全部算出来**，不需要像 RNN 那样一个词等一个词。这就是 Transformer 又快、又不怕长句子的原因：

- **快**：所有词同时算，GPU 可以并行。
- **不怕长**：第 1 个词和第 100 个词之间只隔"一次打分"，不用中间 99 步接力传话。

### 缩放因子（Scaling Factor）：为什么要"除以 √d_k"

把前面三步写成一个公式，就是论文里最有名的那一行，也就是**缩放点积注意力（Scaled Dot-Product Attention）**：

```
Attention(Q, K, V) = softmax( Q × Kᵀ / √d_k ) × V

  Q × Kᵀ      → 第1步：算注意力分数（所有词两两做点积）
  / √d_k      → 缩放：把分数统一缩小一下
  softmax(…)  → 第2步：变成比例
  × V         → 第3步：按比例混合
```

其中 `d_k` 是 K 向量的长度，也就是维度（Dimension）。公式里的 `1/√d_k` 就叫**缩放因子（Scaling Factor）**。

**一句话理解**：打完分之后，把注意力分数**统一缩小一下**，免得分数差距太大，导致模型"只盯着一个词看"。

**为什么需要缩小？** 向量越长，打出来的分数就越大，分数之间的差距也越大。差距一大，换算成比例就会**一边倒**。

**数字例子**：真实模型里向量长度常常是 `d_k = 64`，`√64 = 8`，打出来的分数可能是 `[20, 0, 10]`：

```
不缩小:           分数 [20, 0, 10]      →  比例 100% :  0% :  0%   ← 只看第 1 个词，其他全被忽略
缩小 8 倍(÷√64):  分数 [2.5, 0, 1.25]   →  比例  73% :  6% : 21%   ← 有主有次，比较合理
```

如果总是"只看一个词"，其他词的权重几乎是 0，训练时也几乎收不到梯度（又是梯度消失的老问题），模型就很难学。

**生活类比：考试总分**

- 小测验有 **10 道题**，两个人的总分大概是 `7 分` 和 `5 分`，差距不大。
- 期末考有 **100 道题**，两个人的总分可能变成 `70 分` 和 `50 分`，差距一下子被放大了。

两个人的能力其实差不多，只是**题目多了，总分差距就被放大了**。缩放因子相当于**把总分换算到统一的尺度**，不管考多少题，分数都在差不多的范围里，比较起来才公平。

注意力打分也是一样：向量的每个位置都会贡献一点分数，向量越长，加起来的分数就越大，所以要按向量长度"折算"一下。

**为什么是 √d_k，而不是直接除以 d_k？** 简单记住就行：分数的"波动幅度"大约按 `√d_k` 增长，所以除以 `√d_k` 正好把它拉回正常范围。如果除以 `d_k`，又会缩得太多，分数变得太接近，模型就分不清谁更重要了。

```
没有缩放因子:  向量越长 → 分数越大 → 一边倒 → 只看一个词 → 难训练
有缩放因子:    分数 ÷ √d_k → 回到正常范围 → 有主有次 → 训练稳定
```

> **一句话记住**：缩放因子就像**音量旋钮**，把声音太大的分数调小一点，让每个词都还有被听到的机会。

### 矩阵视角：整句话一次算完

前面"它 → 小猫"的例子只算了**一个词**。实际运行时，整句话的所有词是**打包成矩阵（Matrix）一起算**的。下面用一句 `This is a dog`（4 个词）看看每一步矩阵的形状（Shape）怎么变。

先约定两个记号：

- `n`：句子里有几个词，这里 `n = 4`。
- `d_k` / `d_v`：每个 Key / Value 向量有多长，这里都取 `16`。

**第 1 步：Q 和 K 算出注意力分数（Attention Score）矩阵**

![注意力分数：Q × Kᵀ 得到 4×4 分数矩阵，再 Softmax 得到权重矩阵](/images/attention_score1.png)

- **Q 矩阵**（4 × 16）：每一行是一个词的 Query。第 1 行 `q1` 是 "This" 的，第 4 行 `q4` 是 "dog" 的。
- **K 矩阵**（4 × 16）：同理，每一行是一个词的 Key。
- **分数矩阵 S**（4 × 4）：`s_ij` = 第 i 个词的 Query 和第 j 个词的 Key 做点积，再除以 √d_k。
- **权重矩阵 W**（4 × 4）：对 S 的**每一行**做 Softmax，`w_ij` 就是第 i 个词分给第 j 个词的注意力，每一行加起来等于 1。

形状为什么是 4 × 4？因为 K 要先转置（Transpose）一下：

```
Q      ×  Kᵀ       =  S
(4×16) × (16×4)    =  (4×4)      ← 中间的 16 "消掉"了，剩下 词数 × 词数

一行 = 一个词去给所有 4 个词打分:
         This(K)  is(K)  a(K)  dog(K)
dog(Q)   s_41     s_42   s_43  s_44
```

**数字例子**：假设 "dog" 的 q4 和自己的 k4 做点积（16 个位置相乘再相加）得到 `8`，√16 = 4，缩放后 `s_44 = 8 / 4 = 2`。这就是前面讲的[缩放因子](#缩放因子-scaling-factor-为什么要-除以-√d-k)，向量越长分数越大，所以要除掉。

**第 2 步：权重 × V 得到输出 Z**

![最终结果：4×4 权重矩阵乘以 4×16 的 V，得到 4×16 的输出 Z](/images/attention_score2.png)

```
W      ×  V       =  Z
(4×4)  × (4×16)   =  (4×16)      ← 又变回 "每个词一个 16 维向量"
```

Z 的每一行，就是**对应那个词结合了上下文之后的新表示**。拿 "dog" 这一行来说（权重数字仅为示意）：

```
dog 的权重行:  w_41=0.10   w_42=0.05   w_43=0.05   w_44=0.80     (加起来 = 1)

z_dog = 0.10 × v_This + 0.05 × v_is + 0.05 × v_a + 0.80 × v_dog
      ↑ 一个 16 维向量：主要是 dog 自己的信息，再掺一点其他词的信息
```

这和前面"它 → 小猫"的第 3 步一模一样，只是现在 4 行同时算。

**整个流程串起来**：

```
Q (4×16) ─┐
          ├─ Q×Kᵀ/√16 → S (4×4) ─ 每行 Softmax → W (4×4) ─┐
K (4×16) ─┘                                                ├─ W×V → Z (4×16)
                                         V (4×16) ─────────┘
```

两个值得记住的点：

- **输出形状 = 输入形状**（每个词进去是 16 维，出来还是 16 维）。所以注意力层可以一层一层往上叠。
- **中间那张 n × n 的表就是"谁关注谁"**。句子越长，这张表越大：词数翻倍，表的大小变成 4 倍。这也是 Transformer 处理超长输入时计算量大的原因。

### 多头注意力（Multi-Head Attention）：请几个"专家"从不同角度看

**一句话理解**：一组 Q、K、V 只能学到一种"关注方式"。多头注意力就是**同时用好几组 Q、K、V**，各算各的注意力，最后把结果拼起来。

例子：「小猫喝了牛奶，因为它渴了」里同时存在好几种关系：

```
头1（找指代）: 它   → 小猫        ("它"是谁)
头2（找动作）: 喝了 → 牛奶        (喝了什么)
头3（找因果）: 因为 → 渴了        (为什么)
...
最后: 把所有头的结果拼起来 → 一个更全面的理解
```

原版 Transformer 用了 **8 个头（Head）**：每个词的向量长度是 512，平均分成 8 份，每个头处理 64 维（这也是上面 `d_k = 64` 的来历）。拆成 8 个头以后，总计算量和"一个 512 维的大头"差不多，但能同时看 8 种关系。

**生活类比**：评估一份方案时，请 8 个专家，有人看成本，有人看技术，有人看风险，各自打分，最后汇总意见。比只请 1 个人看得全面。

## 小结

```
注意力机制:   每个词去看别的词，按相关程度分配权重，再按权重混合信息
              Q(我找什么) × K(你有什么) → 打分 → Softmax → 权重 × V(拿走的信息)

Transformer 结构:
              - 编码器 × 6:  自注意力(开会) + 前馈网络(消化)，读懂原文
              - 解码器 × 6:  掩码自注意力 + 交叉注意力 + 前馈网络，一个词一个词写译文
              - 输入先加:    位置编码，告诉模型"谁在第几个"
              - 每一步都带:  残差连接 + 层归一化，让深层网络训练得动
              - 注意力三处:  编码器自注意力、解码器掩码自注意力、交叉注意力
              - 三种变体:    只用编码器(BERT)、只用解码器(GPT)、两个都用(翻译)

Transformer 的注意力:  多头 + 缩放点积 + 自注意力
              - 自注意力:  所有词同时互相看，一次矩阵乘法搞定 → 快、不怕长
              - 缩放:      除以 √d_k，防止 Softmax 一边倒
              - 多头:      多组 Q/K/V 从不同角度看，再合起来
```

## 术语表

### 序列数据（Sequential Data） {.ignore-header}

顺序本身携带信息的数据，比如句子、语音、视频、时间序列传感器数据。

### 循环神经网络（Recurrent Neural Network，RNN） {.ignore-header}

按顺序逐个处理序列元素，并把上一步的隐藏状态传给下一步的网络；每一步共用同一组权重。

### 隐藏状态（Hidden State） {.ignore-header}

RNN/LSTM 在每一步输出的"记忆"向量 `h`，汇总了到目前为止读过的内容。

### 梯度消失（Vanishing Gradient） {.ignore-header}

反向传播时梯度每经过一步就被乘上一个小于 1 的数，传得越远越接近 0，导致靠前的步骤学不到东西。

### 长距离依赖（Long-Range Dependency） {.ignore-header}

句子里隔得很远的两个词之间的关系，比如 30 个词之前的"法国"决定了后面要填"法语"。普通 RNN 很难学会。

### 长短期记忆网络（Long Short-Term Memory，LSTM） {.ignore-header}

在 RNN 基础上加入细胞状态和三个门控的改进版本，能记住更长距离的信息。

### 细胞状态（Cell State） {.ignore-header}

LSTM 里的"记忆传送带" `c`，信息可以在上面几乎不衰减地长距离传递。

### 门（Gate） {.ignore-header}

LSTM 中取值在 0~1 之间的"阀门"，包括遗忘门（Forget Gate）、输入门（Input Gate）、输出门（Output Gate），分别控制保留旧记忆、写入新信息、输出记忆的比例。

### 并行（Parallelize） {.ignore-header}

多个计算同时进行，而不是一个等一个。GPU 擅长并行，Transformer 能让所有词同时算，RNN/LSTM 不行。

### 注意力机制（Attention Mechanism） {.ignore-header}

根据当前输入动态地为各部分分配权重，让输出聚焦于最相关部分的机制。每个元素可以直接和所有其他元素建立联系，是 Transformer 的核心。

### 查询 / 键 / 值（Query / Key / Value，Q / K / V） {.ignore-header}

注意力里每个词变出的三个向量：Q 表示"我在找什么"，K 表示"我有什么"，V 是"被选中后拿走的信息"。由词向量乘上三个可学习的权重矩阵得到。

### 点积（Dot Product） {.ignore-header}

两个向量对应位置相乘再相加，比如 `[1,0]·[2,1] = 1×2 + 0×1 = 2`。结果越大，说明两个向量越"对得上"，注意力用它来给 Q 和 K 打分。

### 归一化指数函数（Softmax） {.ignore-header}

把一组分数换算成加起来等于 1 的比例，分数越高比例越大。注意力里用它把打分变成注意力权重。

### 注意力分数（Attention Score） {.ignore-header}

Query 和 Key 比对后得到的原始打分，表示两个词有多相关，数字大小没有固定范围。在 Transformer 里用点积计算。

### 注意力权重（Attention Weight） {.ignore-header}

把注意力分数经过 Softmax 换算成的比例，加起来等于 1，表示"分给每个词多少注意力"。

### 编码器 / 解码器（Encoder / Decoder） {.ignore-header}

原版 Transformer 的两部分：编码器负责读懂输入（原文），解码器负责一个词一个词地生成输出（译文）。

### 词元（Token） {.ignore-header}

模型处理文字的最小单位，可以简单理解成"一个词"或"一个字"。句子要先切成词元，再变成向量。

### 词嵌入（Word Embedding） {.ignore-header}

把每个词元查表变成一个固定长度的向量（原版 Transformer 是 512 维）。这张表随模型一起训练，意思相近的词向量也相近。

### 位置编码（Positional Encoding） {.ignore-header}

加在词向量上、表示"第几个位置"的向量。注意力本身不区分顺序，靠它让模型分清「狗咬人」和「人咬狗」。

### 前馈网络（Feed-Forward Network，FFN） {.ignore-header}

编码器/解码器每层里的两层全连接网络，每个词单独通过、互不干扰。原版是 512 → 2048 → 512。

### 残差连接（Residual Connection） {.ignore-header}

把一层的输入直接加到它的输出上：输出 = 输入 + 新学到的。和 ResNet 的跳跃连接相同，防止信息在深层网络里丢失。

### 层归一化（Layer Normalization） {.ignore-header}

把每个词自己的向量拉回"平均值 0、标准差 1"左右，让数值稳定。和批归一化的区别是：它按单个词归一化，不依赖一批数据。

### 标准差（Standard Deviation） {.ignore-header}

一组数平均离它们的平均值有多远。比如 `[2, 4, 6]` 平均值是 4，标准差约 1.63；数字越分散，标准差越大。

### 自回归（Autoregressive） {.ignore-header}

生成时每次只输出一个词，再把它接到输入末尾去生成下一个词，直到输出"结束"符号。

### 推理（Inference） {.ignore-header}

训练好的模型拿来实际使用、对新输入给出结果的过程。Transformer 生成文字时，推理只能一个词一个词地往外写。

### 词表（Vocabulary） {.ignore-header}

模型认识的所有词元组成的列表，比如 30000 个。输出时要给词表里每个词打分，挑出下一个词。

### 线性层（Linear Layer） {.ignore-header}

就是全连接层：输入向量乘一个权重矩阵再加偏置。Transformer 最后用它把 512 维向量变成词表大小的分数。

### 大语言模型（Large Language Model，LLM） {.ignore-header}

用海量文本训练的超大 Transformer（通常只用解码器），比如 GPT、Claude，擅长续写和对话。

### 视觉 Transformer（Vision Transformer，ViT） {.ignore-header}

把图片切成图像块（Patch），每块当成一个"词"送进 Transformer 编码器来做图像识别。

### 检测 Transformer（Detection Transformer，DETR） {.ignore-header}

用 Transformer 做目标检测的模型，每个查询直接负责一个物体，一个物体只出一个框，不需要 NMS。

### 自注意力（Self-Attention） {.ignore-header}

Q、K、V 都来自同一句话的注意力，句子里的词互相看；所有词可以用一次矩阵乘法同时算完。

### 缩放点积注意力（Scaled Dot-Product Attention） {.ignore-header}

Transformer 使用的打分方式：`softmax(Q × Kᵀ / √d_k) × V`。除以 `√d_k` 是为了防止分数过大导致 Softmax 一边倒。

### 缩放因子（Scaling Factor） {.ignore-header}

缩放点积注意力里的 `1/√d_k`：把注意力分数统一缩小，防止向量太长时分数差距过大、权重一边倒，让训练更稳定。

### 多头注意力（Multi-Head Attention） {.ignore-header}

同时用多组 Q/K/V 各算一次注意力，再把结果拼起来，让模型从多个角度捕捉不同的关系。原版 Transformer 用 8 个头。

### 掩码自注意力（Masked Self-Attention） {.ignore-header}

解码器里的自注意力，把"还没生成"的位置遮住（分数设成负无穷），保证生成时不偷看后面的答案。

### 交叉注意力（Cross-Attention） {.ignore-header}

Q 来自一句话、K 和 V 来自另一句话的注意力，比如翻译时译文去原文里找对应内容。
