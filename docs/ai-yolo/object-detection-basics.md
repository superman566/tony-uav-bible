# 目标检测基础（Object Detection）

> [卷积神经网络（CNN）](/ai-yolo/cnn-basics) 讲的是"这张图里画的是什么"——CNN 把图片一路压缩成一个类别标签（0~9 的数字、猫或狗……）。但现实任务经常还要多问一句："这个东西在图片的**哪个位置**？"这就是目标检测（Object Detection）要解决的问题，也是接下来要学的 YOLO 系列模型的目标。

## 目标识别基础

### 目标检测 vs 目标识别

一句话区分：**目标检测（Object Detection）**回答"图里有什么 + 在哪个位置"，输出若干组「类别 + 边界框（Bounding Box）」；**目标识别（Object Recognition）**只回答"这是什么"，不管位置，更接近图像分类（Image Classification）。

两者常配合使用——比如人脸场景里，先用人脸检测（Face Detection）框出"这里有一张脸"（位置），再用人脸识别（Face Recognition）判断"这张脸是谁"（身份）。打个比方：目标识别像是看一张全家福只回答"照片里有没有小孩"；目标检测则要把每个小孩单独用框圈出来。

### 目标检测的挑战，以及深度学习怎么应对

目标检测比图像分类难，原因是要同时应对下面这些问题——好在深度学习靠"从数据里自动学特征"而不是人工设计规则（对比[经典计算机视觉核心技术与算法](/ai-yolo/classic-cv-algorithms)开头讲的传统方法"所有规则都由人工设计"），对每一类挑战基本都有对应的解法：

| 挑战 | 难在哪 | 深度学习的应对 |
|-|-|-|
| 尺度变化 / 小目标（Scale Variation） | 同一类物体忽大忽小，小目标像素少，容易在下采样中"消失" | 多尺度特征图分别检测大/中/小目标；[感受野](/ai-yolo/cnn-basics#感受野-receptive-field)随层数加深覆盖更大范围 |
| 遮挡（Occlusion） | 物体被部分挡住，只能看到局部特征 | CNN 学的是"边缘→部件→物体"的层级特征，见到关键部件也能识别出整体，见[CNN 层级特征](/ai-yolo/cnn-basics) |
| 形变 / 类内差异大（Intra-class Variation） | 同一类别姿态、外观差异很大 | 大规模数据训练，自动覆盖各种变体，无需人工设计固定模板 |
| 视角 / 光照 / 运动模糊（Viewpoint / Illumination / Motion Blur） | 同一物体因角度、光线、模糊而"看起来不一样" | 数据增强（Data Augmentation）让模型训练时提前"见过"这些变化（[AlexNet 就是这么做的](/ai-yolo/cnn-basics#alexnet-比-lenet-5-多用的几个关键技巧)） |
| 背景复杂（Background Clutter） | 杂乱背景容易被误判成目标 | 端到端学习（End-to-End Learning）让网络自己学会该关注哪里、忽略哪里 |
| 类别不平衡（Class Imbalance） | 背景框数量远多于目标框 | Focal Loss 等针对性损失函数，压低易分类背景样本的权重 |
| 实时性与算力限制（Real-time Constraint） | 需要在有限算力下快速出结果 | [一阶段检测器](#生成候选框-region-proposal-anchor)（YOLO 这种单次前向传播）+ GPU 并行计算 |
| 标注成本高（Annotation Cost） | 边界框标注比分类标签费时费力 | 迁移学习（Transfer Learning），复用预训练模型减少标注需求 |

一句话总结：**深度学习把"人工设计规则"换成了"从数据里自动学规则"，大部分挑战最终都变成"喂对数据"和"用对损失函数/网络结构"的工程问题，而不是像传统方法那样，遇到一种新情况就要重新设计一套特征。**

## 目标检测的基本步骤

**一句话理解**：不管是哪种目标检测模型，干的事情都能拆成 4 个固定动作——先把图片变成带语义的特征，再在图上"撒"一批候选框，然后给每个候选框打分（是什么类别）并微调框的位置，最后把重复的框去掉，只留下最靠谱的那几个。

```
输入图片 → ①特征提取 → ②生成候选框 → ③分类 + 边界框回归 → ④非极大值抑制（NMS）
                                                                    ↓
                                                    输出：类别 + 边界框 + 置信度
```

### 特征提取（Feature Extraction）

用 [CNN backbone](/ai-yolo/cnn-basics#骨干网络-backbone) 把原始像素图片压缩成带有语义信息的[特征图（Feature Map）](/ai-yolo/cnn-basics#特征图-feature-map)——这一步跟图像分类完全一样，都是"卷积 + 池化"反复堆叠：一张 416×416×3 的图片，一路压缩成比如 13×13×1024 的特征图，特征图上每个点都浓缩了原图一片区域的语义信息（对应[感受野](/ai-yolo/cnn-basics#感受野-receptive-field)）。

### 生成候选框（Region Proposal / Anchor）

在特征图上预设一批不同大小、比例的候选框（锚框，Anchor Box），作为"这里可能有个物体"的初始猜测——下一步的分类和坐标微调都是在这些候选框基础上做的，而不是让网络凭空去猜一个框的坐标。

- **两阶段检测器（Two-stage Detector）**，比如 Faster R-CNN：专门用一个小网络（区域候选网络，Region Proposal Network，RPN）先粗筛一遍，挑出"看起来像有物体"的候选框，再交给下一步精细分类，相当于"先海选，再精选"。
- **一阶段检测器（One-stage Detector）**，比如后面要学的 YOLO：不单独海选，直接在特征图每个网格点上放几个预设大小的 anchor，一步到位判断类别和位置，所以更快——这也是前面"目标检测的挑战"那张表里"一阶段检测器 + 单次前向传播"能满足实时性要求的原因。

### 分类 + 边界框回归（Classification + Bounding Box Regression）

对每一个候选框，网络同时做两件事：

```
分类分支：这个框里是猫、狗，还是背景？ → 输出每个类别的概率
回归分支：这个框离物体的真实边界还差多少？ → 输出 (dx, dy, dw, dh) 4 个修正量，微调框的中心点和宽高
```

打个比方：候选框像是先用铅笔随手画的一个大概的框，回归分支就是把这个框"描"得更贴近物体的真实轮廓。

### 非极大值抑制（Non-Maximum Suppression, NMS）

同一个物体附近往往会同时冒出好几十个候选框、且分数都不低，如果全部保留，一个物体就会被重复框出好几次。NMS 的做法：

```
1. 把所有候选框按置信度从高到低排序
2. 取分数最高的框，保留下来
3. 把和它重叠度（IoU，交并比，Intersection over Union）超过某个阈值（比如 0.5）的框全部删掉——这些框大概率框的是同一个物体
4. 对剩下的框重复步骤 2、3，直到所有框都处理完
```

### 完整走一遍：检测图片里的一只狗

```
①特征提取：416×416 的图片 → 压缩成 13×13 的特征图
②生成候选框：13×13 个网格点，每个点放 3 个不同大小的 anchor → 共 13×13×3 = 507 个候选框
③分类+回归：507 个框里，20 个框判断为"狗"且分数 > 0.5，其余 487 个框判断为背景；
            这 20 个框的坐标也各自被微调，更贴近狗的真实轮廓
④NMS：这 20 个框彼此重叠度（IoU）都很高，NMS 只保留分数最高的 1 个，删掉其余 19 个
最终输出：1 个框 + 类别"狗" + 置信度 0.92
```

一句话总结：**特征提取负责"看懂图"，生成候选框负责"提出候选位置"，分类+回归负责"判断是什么、精调在哪"，NMS 负责"去重"——四步串起来，就是从一张原始图片走到"类别 + 框 + 置信度"这个最终输出的完整流程。**

## 目标检测数据集（Benchmark Dataset）

### 为什么要专门讲数据集

后面迁移学习那节会提到"在 ImageNet 上训练好的模型"——这类被反复拿来当训练/评测标准的公开数据集，叫基准数据集（Benchmark Dataset）。目标检测领域最常被提到的三个是 **ImageNet**、**Pascal VOC**、**COCO**，它们出现的时间不同、要解决的任务也不同，代表了这个领域一步步变难、变真实的过程。

### ImageNet（图像分类数据集）

**一句话理解**：一个超大规模的"图片 + 类别标签"题库，图里有什么就标什么，不需要标出物体在图片里的位置。

- 规模：全集约 1400 万张图片、2.2 万+ 类别；比赛常用子集 ILSVRC 有 1000 类、约 120 万张训练图（也就是下面迁移学习里提到的那 120 万张）。
- 任务：图像分类（Image Classification）——给一张图判断"这是猫还是狗"，不用框出猫在图里的哪个位置。
- 历史意义：2012 年 AlexNet 在 ImageNet 比赛上把错误率从 26% 降到 16%，直接引爆了这一轮深度学习革命（见 [AlexNet](/ai-yolo/cnn-basics#alexnet-比-lenet-5-多用的几个关键技巧)），也正因为规模够大、覆盖面够广，"用 ImageNet 预训练、再迁移到别的任务"这件事才这么好用。

### Pascal VOC（早期目标检测数据集）

**一句话理解**：比 ImageNet 更进一步——不只说图里有什么，还要用一个[边界框](#边界框-bounding-box)把它圈出来。

- 规模：远小于 ImageNet，常用的 VOC2007 + VOC2012 合计约 2 万多张图片，只有 **20 个类别**（人、猫、狗、汽车、自行车、沙发……都是生活常见物体）。
- 任务：目标检测（Object Detection）+ 语义分割（Semantic Segmentation），既要分类又要给出位置。
- 特点：图片通常干净、简单，一张图往往只有 1~2 个物体、背景不复杂，很适合用来快速验证新算法（早期的 R-CNN、YOLO v1、SSD 都是先在 VOC 上跑通的），但也正因为太"干净"，被认为不够贴近真实世界。

### COCO（Common Objects in Context）

**一句话理解**：故意找"复杂、拥挤、日常生活中的真实场景"来标注——一张图里可能同时有十几个互相遮挡的物体，比 VOC 难得多。

- 规模：约 33 万张图片，80 个类别，标注了超过 150 万个物体实例。
- 任务：目标检测 + 实例分割（Instance Segmentation，不仅框出来，还要抠出精确轮廓）+ 关键点检测（Keypoint Detection，比如人体关节点）。
- 举个例子：一张厨房的照片里可能同时标了 `person`（正在切菜、被冰箱挡住一半身子的人）、`knife`、`bowl`、`refrigerator`——物体之间互相[遮挡](#遮挡-occlusion)、大小不一，正好呼应前面"目标检测的挑战"那张表里提到的遮挡、尺度变化、背景复杂这几项。
- 现状：因为更贴近真实世界的复杂度，现在几乎所有目标检测论文（包括后面要学的 YOLO 系列）都用 **COCO mAP**（在 COCO 数据集上的平均精度）作为衡量模型好坏的标准跑分。

### 三者对比

| | ImageNet | Pascal VOC | COCO |
|-|-|-|-|
| 核心任务 | 图像分类 | 目标检测 / 分割 | 检测 / 分割 / 关键点 |
| 类别数 | 1000（常用子集） | 20 | 80 |
| 场景复杂度 | 单物体为主 | 简单，背景干净 | 复杂，多物体、遮挡多 |
| 历史角色 | 引爆深度学习革命，常作预训练来源 | 早期检测算法的练兵场 | 现代检测模型的标准考场 |

一句话总结：**可以把这三个数据集想象成"考试难度升级"——ImageNet 是"这张图里是什么类别"的选择题；VOC 是在此基础上"把物体圈出来"的简单填空；COCO 则是"一张挤满了人和物体、还互相挡着"的综合大题，专门用来检验模型在真实世界里到底扛不扛用。**

## 迁移学习（Transfer Learning）

### 什么是迁移学习

**一句话理解**：迁移学习（Transfer Learning）是把一个已经在大规模数据集（比如 ImageNet，约 120 万张图）上训练好的模型，拿到新任务上继续微调（Fine-tune），而不是让新任务的模型从随机初始化的权重从零学起。

### 为什么目标检测需要迁移学习

目标检测特别依赖迁移学习，原因有三个：

1. **标注成本高，数据量往往不够**（呼应上面"标注成本高"这条挑战）——目标检测数据集通常比分类数据集小得多（每张图都要精确标边界框，比打一个分类标签费力得多），从零训练深层网络容易[过拟合](/ai-yolo/dl-basics)（死记硬背这几千张图，换一批新图就不准）。
2. **底层视觉特征是通用的**——CNN 浅层学到的边缘、纹理这些特征（见[感受野](/ai-yolo/cnn-basics#感受野-receptive-field)那节"层数越浅看得越细"），不管是分类任务还是检测任务都用得上，没必要每个新任务都重新学一遍，这正是[骨干网络（Backbone）](/ai-yolo/cnn-basics#骨干网络-backbone)可以被复用的原理。
3. **能大幅减少训练时间和所需数据量**——只需要在预训练好的 backbone 基础上微调后面几层去适应新场景，比从零训练收敛快得多。

### 具体怎么做

```
第一步：拿一个在 ImageNet 上训练好的 ResNet（backbone），已学会通用的边缘/纹理/部件特征
第二步：去掉它原本的分类头（输出 1000 类的那一层）
第三步：接上目标检测专用的"头"（预测边界框坐标 + 类别）
第四步：分阶段冻结/解冻 backbone，继续训练整个网络（见下面）
```

这也是为什么几乎所有目标检测框架（包括后面要学的 YOLO）都默认提供"预训练权重（Pretrained Weights）"作为起点，而不是要求用户自己从零训练。

**第四步为什么要"分阶段"**：不能一上来就把预训练好的 backbone 和随机初始化的检测头放在一起、用正常学习率整体训练——检测头一开始的梯度很乱（毕竟是瞎猜），反向传播回 backbone 会把已经学好的通用特征带偏，这叫灾难性遗忘（Catastrophic Forgetting）。实践中常用冻结（Freeze）部分层的方式来避免这个问题，典型流程分三步：

```
阶段 1（Warmup，冻结 backbone，只训练检测头）：
  冻结整个 backbone，学习率相对大（比如 1e-3），训练几个 epoch，让检测头先"跟上"

阶段 2（Fine-tune，解冻部分层）：
  解冻 backbone 靠后的几层（比如 ResNet 的 Stage3、Stage4），学习率调小（比如 1e-4）
  浅层继续冻结不动——CNN 浅层学的是边缘、纹理这类通用特征（见感受野那节），换任务也用得上

阶段 3（可选，数据量足够大时）：
  解冻全部层，用更小的学习率（比如 1e-5）整体微调
```

冻多少层取决于新数据集有多大：数据集越小，越应该多冻结（甚至只训练检测头，防止[过拟合](/ai-yolo/dl-basics)）；数据集越大，越可以放开更多层甚至全部解冻，让模型有更大自由度去适应新任务。

## 数据增强（Data Augmentation）

### 什么是数据增强

**一句话理解**：数据增强是在训练时对原始图片做各种随机变换（旋转、翻转、裁剪、调亮度、加模糊/噪声……），从同一张图"人工造出"很多张长得不一样、但本质内容没变的新图片，相当于变相扩大了训练集规模——而且不需要真的再去标注一张新图。

具体例子：假设训练集里只有 1 张猫的照片，每个 epoch（训练轮次）给它套用不同的随机变换：

```
原图                  → 猫，正面，光线正常
随机水平翻转          → 猫，镜像过来，还是那只猫
随机旋转 ±15°         → 猫，稍微歪了一点头
随机裁剪              → 只露出猫的上半身
随机调亮度/对比度      → 猫，看起来像是在阴天拍的
```

这 5 张图对人来说"看一眼就知道还是同一只猫"，但对模型来说，输入的像素数值完全不同——相当于用 1 张图喂出了 5 种不同的训练样本。

### 为什么需要数据增强

1. **标注数据往往不够，尤其是目标检测**（呼应上面"标注成本高"这条挑战）——每张图都要精确标边界框，比分类打一个标签费力得多，实际能拿到的标注数据集通常有限。
2. **防止过拟合**——深度网络参数量大（[AlexNet 光三层全连接就近 5900 万参数](/ai-yolo/cnn-basics#alexnet-比-lenet-5-多用的几个关键技巧)），训练数据太少容易死记硬背（[过拟合](/ai-yolo/dl-basics)）；数据增强让模型每一轮看到的都是"新"样本，很难死记硬背。
3. **让模型对现实世界的各种变化更鲁棒**——回到上面"目标检测的挑战"那张表，视角变化、光照变化、运动模糊这几个挑战本质都是"同一个物体，看起来不一样了"；数据增强就是训练时提前让模型"见过"这些变化，测试时真遇到就不会懵。
4. **几乎零成本**——比起真的多拍、多标注一批新图片，数据增强只是计算层面的随机变换，不需要额外的人工标注成本。

一句话总结：**数据增强用"计算换数据"，让模型在不增加标注成本的前提下见过更多样的样本，既能防止过拟合，又能提前适应现实世界的各种变化。**

## 术语表

### 目标检测（Object Detection） {.ignore-header}

对一张图片里的物体，同时判断"是什么类别"和"在哪个位置（框）"，输出若干组"类别 + 边界框"。

### 目标识别（Object Recognition） {.ignore-header}

判断图片（或图片中某一块区域）里"是什么"，输出一个类别标签，不涉及位置信息，更接近图像分类（Image Classification）。

### 边界框（Bounding Box） {.ignore-header}

能刚好框住一个物体的矩形，常见用「中心点+宽高」或「左上角+右下角」两种方式记录 4 个数字来描述。

### 候选框 / 锚框（Anchor Box） {.ignore-header}

在特征图上预先设定好的一批不同大小、比例的框，作为"这里可能有个物体"的初始猜测；后续的分类和坐标微调都建立在这些候选框之上，而不是让网络凭空预测坐标。

### 边界框回归（Bounding Box Regression） {.ignore-header}

网络对每个候选框预测 4 个修正量（中心点偏移 + 宽高缩放），把候选框微调得更贴近物体的真实边界，是目标检测里"精调位置"这一步的核心操作。

### 交并比（IoU, Intersection over Union） {.ignore-header}

两个框的重叠程度，等于「两框相交的面积」除以「两框相并的面积」，取值 0~1，越接近 1 说明两个框重合得越好；常用来判断预测框是否够准，也是 NMS 去重的判断依据。

### 非极大值抑制（Non-Maximum Suppression, NMS） {.ignore-header}

同一个物体附近常有多个高分候选框，NMS 只保留分数最高的框，删掉与它重叠度（IoU）超过阈值的其他框，避免同一个物体被重复框出。

### 两阶段检测器（Two-stage Detector） {.ignore-header}

先用一个专门的网络（如 RPN）粗筛候选框，再对筛出来的候选框做精细分类和坐标微调，相当于"先海选、再精选"，代表模型如 Faster R-CNN，精度较高但速度较慢。

### 一阶段检测器（One-stage Detector） {.ignore-header}

不做单独的候选框海选，直接在特征图每个位置一步到位输出类别和坐标，速度更快，代表模型如 YOLO，是满足实时检测需求的常见选择。

### 遮挡（Occlusion） {.ignore-header}

物体被其他物体挡住一部分，模型只能看到局部特征，是目标检测常见的挑战之一。

### 数据增强（Data Augmentation） {.ignore-header}

训练时对原始图片做随机旋转、裁剪、调整亮度、加模糊等变换，相当于"人工造出"更多训练样本，让模型提前"见过"各种视角/光照/模糊场景，缓解这些变化带来的检测难度。

### 类别不平衡（Class Imbalance） {.ignore-header}

一张图里背景区域远多于目标区域，训练时负样本（背景框）远多于正样本（目标框），需要用 Focal Loss 等针对性方法处理，否则模型容易偏向预测"没有目标"。

### 端到端学习（End-to-End Learning） {.ignore-header}

让网络直接从原始输入学到最终输出，中间该关注什么特征、忽略什么背景，都由损失函数反向传播自动调整，不需要人工设计中间步骤的规则。

### 基准数据集（Benchmark Dataset） {.ignore-header}

领域内被反复用来训练、比赛、评测模型的公开标准数据集，方便不同论文、不同算法在同一把尺子下比较效果，比如目标检测领域常提到的 ImageNet、Pascal VOC、COCO。

### ImageNet {.ignore-header}

超大规模图像分类数据集，常用子集 ILSVRC 有 1000 类、约 120 万张训练图，只标"图里是什么"，不标位置；2012 年 AlexNet 在此比赛上的突破引爆了深度学习革命，现在也常被用作迁移学习的预训练来源。

### Pascal VOC {.ignore-header}

早期的目标检测/分割数据集，20 个类别、约 2 万多张图，场景简单干净，是早期检测算法（R-CNN、YOLO v1 等）常用的验证数据集。

### COCO（Common Objects in Context） {.ignore-header}

贴近真实生活场景的目标检测数据集，80 个类别、约 33 万张图，一张图常有多个互相遮挡的物体，现在是目标检测模型最常用的标准评测基准（常用 COCO mAP 作为跑分指标）。

### 迁移学习（Transfer Learning） {.ignore-header}

把一个在大数据集（比如 ImageNet）上预训练好的模型，拿到新任务的小数据集上继续微调（Fine-tune），减少新任务从零开始需要的标注数据量。

### 预训练权重（Pretrained Weights） {.ignore-header}

模型在大规模数据集（比如 ImageNet）上训练好之后保存下来的参数，可以直接加载作为新任务的起点，再用迁移学习微调，而不用从随机初始化开始训练。

### 冻结（Freeze） {.ignore-header}

微调时让某些层的参数在训练中保持不变、不参与梯度更新，通常用来保护预训练模型里已经学好的通用特征不被打乱，也能减少参与训练的参数量、防止小数据集上过拟合。

### 灾难性遗忘（Catastrophic Forgetting） {.ignore-header}

微调时如果不加保护地用新任务的数据整体训练，新任务里不成熟的梯度（比如随机初始化的检测头）反向传播回预训练好的层，会把原本学到的通用特征覆盖掉——这是迁移学习里需要用冻结、调小学习率等方式规避的问题。
